# Saifur Rahman — Portfolio

A modern and responsive personal portfolio website showcasing my work, skills, professional experience, education, and web development projects.

I am **Saifur Rahman**, a **Web Designer & Developer** based in Sylhet, Bangladesh. I work with modern frontend technologies including JavaScript, React, Next.js, and Tailwind CSS, along with professional experience building and maintaining WordPress websites.

## Features

- Fully responsive design for desktop, tablet, and mobile
- Light and dark theme
- Professional portfolio introduction
- Skills and technologies section
- Professional experience
- Education and training
- Featured development projects
- Dedicated project detail pages
- Resume/CV preview and PDF download
- GitHub, LinkedIn, and Instagram integration
- Contact information
- Clean and modern user interface

## Getting Started

Clone the repository:

```bash
git clone https://github.com/saifurbinkobir/saifur-rahman-portfolio.git
```

Go to the project directory:

```bash
cd saifur-rahman-portfolio
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open:

```text
http://localhost:3000
```
